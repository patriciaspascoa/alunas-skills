# Backstage PRO — Skills para Alunas

Skills para Claude Code de uso da comunidade Backstage PRO.

## Instalação

```bash
/plugin marketplace add patriciaspascoa/alunas-skills
/plugin install pagina-de-vendas@alunas-skills
```

## Skills disponíveis

| Skill | Descrição |
|---|---|
| pagina-de-vendas | Cria páginas de vendas que convertem (MD primeiro, HTML após aprovação) ou audita páginas existentes |

## Como usar

Após instalar, use `/pagina-de-vendas` no Claude Code, ou simplesmente descreva o que precisa (criar página nova, auditar página existente) que a skill ativa automaticamente.

## Atualizações

Quando uma skill for atualizada neste repositório, rode para puxar a versão nova:

```bash
/plugin marketplace update alunas-skills
```
